Latest release

Which build do I need?

ServerBuildJava
Spigot, Paper, Purpur, Leaves, any Bukkit fork …-bukkit.jar 8+
Folia …-folia.jar 17+

The two jars are not interchangeable. The Folia build declares folia-supported: true and uses region schedulers; the Bukkit build uses the classic scheduler that Folia does not ship. Installing the wrong one fails at startup rather than silently misbehaving — see Bukkit & Folia builds for the details.

After downloading

  1. Stop the server

    Do not hot-swap jars while the server is running.

  2. Drop the jar into plugins/

    Leave it zipped — the server loads the jar as-is.

  3. Start the server

    The first start writes plugins/CreeperConfettiPro/config.yml and all 18 language files.

  4. Tune it

    /cc gui in game, or edit the config and run /cc reload.

下载之后

  1. 停止服务端

    不要在服务端运行时热替换 jar。

  2. 把 jar 放进 plugins/

    保持压缩包原样，服务端会直接加载 jar。

  3. 启动服务端

    首次启动会生成 plugins/CreeperConfettiPro/config.yml 与全部 18 个语言文件。

  4. 开始调整

    游戏内用 /cc gui，或者改配置后执行 /cc reload。
