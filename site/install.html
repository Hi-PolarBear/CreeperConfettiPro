Installation

Two steps: put the right jar into plugins/, restart the server. Everything else can be configured afterwards from inside the game.

Requirements

ItemBukkit buildFolia build
Server Spigot / Paper / Purpur and other Bukkit forks, api-version: 1.13 Folia, api-version: 1.19, folia-supported: true
MC version 1.13 and newer (compiled against the 1.9.4 API) 1.19.4 and newer
Java Java 8+ Java 17+
Dependencies None — bStats and commons-lang3 are shaded into the jar
i

The Bukkit build targets Java 8 and should load on 1.8–1.12 servers too (those versions ignore the api-version field), but the project is not tested there. Use 1.13+ in production.

Install steps

  1. Check your server type

    Plain Bukkit / Spigot / Paper → bukkit build. Only Folia needs the folia build. Both jars share the same plugin name and cannot coexist.

  2. Get the jar

    Grab it from the download page, or build it yourself:

    CreeperConfettiPro-bukkit/target/CreeperConfettiPro-4.1.0-bukkit.jar
CreeperConfettiPro-folia/target/CreeperConfettiPro-4.1.0-folia.jar
  3. Copy it into plugins/

    Do not unzip it.

  4. Restart the server

    Use restart or a full stop/start. The first enable writes the config and every language file — a /reload is not enough for that.

  5. Tune the settings

    Edit plugins/CreeperConfettiPro/config.yml then run /cc reload, or just use /cc gui in game.

What the first start creates

The data folder is always plugins/CreeperConfettiPro/:

plugins/CreeperConfettiPro/
├── config.yml                 # main config: chance, aliases, language, styles
├── languages/                 # 18 language files, editable
│   ├── en_us.yml
│   ├── zh_cn.yml
│   └── ...
└── backups/                   # only created during config migration
    └── config-backup-20261101-060732.yml

Language files are only written when they are missing, so your edits are never overwritten. Delete a file and restart to get the original text back.

Verify the install

The console prints a gold-framed banner with the version, branch author and the server's Java version, ending with plugin enabled successfully. Right after it comes the active language:

----------------------------------------
    CreeperConfettiPro plugin is loading...
    Version: 4.1.0-bukkit
    Branch Author: Hi_PolarBear
    Server Java Version: 17.0.9
----------------------------------------
    CreeperConfettiPro plugin enabled successfully!
    Thank you for using this plugin!
----------------------------------------
Current plugin language: English (en_us)

Then confirm two things in game:

  • /cc help shows the paginated help screen;
  • a summoned creeper leaves a firework and a bang, and no crater.
# run in chat or from the console
/summon minecraft:creeper ~ ~ ~ {ExplosionRadius:3,Fuse:20}
v

If /cc reports an unknown command, try the full command /creeperconfetti help first. If both work, aliases are registered correctly. If only the full one works, the alias is taken by another plugin or disabled in the config — see FAQ.

Uninstall & roll back

  1. Stop the server.
  2. Delete plugins/CreeperConfettiPro-4.1.0-*.jar.
  3. (Optional) delete plugins/CreeperConfettiPro/ — this also removes your custom styles and translations.
  4. Start the server.

The plugin never writes into world or player data, so removing it leaves the world untouched — the explosions it cancelled never happened in the first place.

!

To keep your tuned styles, back up config.yml and languages/ before uninstalling. Put them back in place after reinstalling and the plugin picks them up as-is.

安装与部署

整个安装过程只有两步：把正确的 jar 放进 plugins/，重启服务端。所有配置都可以在启动后通过游戏内指令完成。

环境要求

项目Bukkit 分支Folia 分支
服务端 Spigot / Paper / Purpur 等 Bukkit 系，api-version: 1.13 Folia，api-version: 1.19，folia-supported: true
MC 版本 1.13 及以上（编译基于 1.9.4 API） 1.19.4 及以上
Java Java 8 及以上 Java 17 及以上
依赖 无。bStats 与 commons-lang3 已通过 shade 打进 jar 内部
i

Bukkit 分支以 Java 8 为目标编译，理论上能在 1.8–1.12 的服务端加载（这些版本会忽略 api-version 字段），但项目未对这些版本做测试。生产环境建议使用 1.13 以上。

安装步骤

  1. 确认服务端类型

    普通 Bukkit / Spigot / Paper 用 bukkit 分支；只有 Folia 才用 folia 分支。两者插件名相同，不能共存。

  2. 取得 jar

    从 下载页 获取，或自行构建：

    CreeperConfettiPro-bukkit/target/CreeperConfettiPro-4.1.0-bukkit.jar
CreeperConfettiPro-folia/target/CreeperConfettiPro-4.1.0-folia.jar
  3. 放入插件目录

    把 jar 复制到服务端的 plugins/ 文件夹，不要解压。

  4. 重启服务端

    使用 restart 或完全停止后启动。首次启用会生成配置文件与全部语言文件，这一步不能靠 /reload 完成。

  5. 调整设置

    可以编辑 plugins/CreeperConfettiPro/config.yml 后执行 /cc reload，也可以直接在游戏里用 /cc gui 操作。

首次启动会生成什么

插件的数据目录固定为 plugins/CreeperConfettiPro/：

plugins/CreeperConfettiPro/
├── config.yml                 # 主配置：概率、别名、语言、烟花样式
├── languages/                 # 18 个语言文件，可直接编辑
│   ├── zh_cn.yml
│   ├── en_us.yml
│   └── ...
└── backups/                   # 仅在配置迁移时生成
    └── config-backup-20261101-060732.yml

语言文件只有在不存在时才会被写入，所以你改过的翻译不会被覆盖。想恢复原始文案，删掉对应文件后重启即可重新生成。

验证安装

启动时控制台会输出一段带金色分隔线的启动信息，包含版本号、分支作者、服务器 Java 版本，最后一行是 plugin enabled successfully。随后还有一行当前语言提示：

----------------------------------------
    CreeperConfettiPro 插件正在加载中...
    Version: 4.1.0-bukkit
    Branch Author: Hi_PolarBear
    Server Java Version: 17.0.9
----------------------------------------
    CreeperConfettiPro 插件已成功启用！
    感谢使用本插件！
----------------------------------------
当前插件语言: 简体中文 (zh_cn)

进游戏后再确认两件事：

  • 输入 /cc help 能看到分页帮助；
  • 召唤并引爆一只苦力怕，正常应当只看到烟花与爆炸音效，脚下不留坑。
# 在聊天栏或控制台执行
/summon minecraft:creeper ~ ~ ~ {ExplosionRadius:3,Fuse:20}
v

如果 /cc 提示未知指令，先试完整指令 /creeperconfetti help。两者都能用时，说明别名注册正常；只有完整指令可用，则是别名被其他插件占用或被配置关闭了，处理方法见 常见问题。

卸载与回滚

  1. 停止服务端。
  2. 删除 plugins/CreeperConfettiPro-4.1.0-*.jar。
  3. （可选）删除数据目录 plugins/CreeperConfettiPro/，这会一并清除自定义样式与语言修改。
  4. 启动服务端。

插件不会往世界数据或玩家数据里写任何东西，因此卸载后世界状态完全不受影响——之前被取消的爆炸本来就没有留下痕迹。

!

如果要保留自己调好的样式，卸载前先备份 config.yml 与 languages/。重新安装时把它们放回原位置，插件会直接沿用。
