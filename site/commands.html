Commands & permissions

The root command is /creeperconfetti, with /cc and /confetti registered as aliases. Every feature is a subcommand.

Command overview

SubcommandAliasesPurposePlayers only
help [page|command]?, hPaginated help with clickable page buttonsno
effect <action>effects, style, styles, fireworkManage styles and per-style chancessome
chance [percent]probability, percentView or set the overall chanceno
guimenuOpen the in-game style manageryes
language <action>langView, switch and reload languagesno
reloadrlReload config, styles, language and aliasesno

Running /cc with no arguments is the same as /cc help. An unknown subcommand prints a hint and opens the first help page.

/cc effect

Everything about styles lives here. Brackets are optional arguments, angle brackets are required.

UsageDescriptionPermissionRestriction
/cc effect listList every style: index, name, effect count, current chanceeffect—
/cc effect add [name]Save the rocket in your hand as a new style; without a name it becomes style1, style2…effectplayers only
/cc effect set <name>Overwrite a style with the rocket in your hand (creates it if missing)effectplayers only
/cc effect remove <name>Delete a style; alias deleteeffect—
/cc effect resetRestore the four built-in styles and rebalance the chanceseffect—
/cc effect preview [name]Preview a style at your feet; without a name a random one is previewed; alias testeffectplayers only
/cc effect chanceShow every chance and the totaleffect—
/cc effect chance <name> <percent>Pin one style to a chance; the rest are compensatedeffect—
/cc effect chance resetReset all chances to an even spliteffect—

Examples

# what is configured right now
/cc effect list

# hold a rocket with an effect, save it as "festival"
/cc effect add festival

# give it half of the weight; the others share the rest
/cc effect chance festival 50

# preview it on its own
/cc effect preview festival

# remove it
/cc effect remove festival

Style names are case-insensitive: Classic and classic are the same style. The original capitalisation is kept for display and when writing back to the config.

i

add and set automatically preview the style at your position on success, so you do not need a separate preview.

/cc chance

UsageDescription
/cc chanceShow the current overall chance
/cc chance <0-100>Set the overall chance; written to the config immediately
 
/cc chance 100     # every creeper becomes a firework
/cc chance 5       # five percent
/cc chance 0       # effectively disable it

Values outside 0–100 or non-numbers are rejected with a message. This value and the per-style weights are two separate dimensions: first the plugin decides whether to convert, then it draws a style.

/cc gui

Opens the 54-slot style manager. Same capabilities as /cc effect, but visual. Requires creeperconfetti.command.effect and a player. See In-game GUI.

/cc language

UsageDescription
/cc language or /cc language infoShow the current language's display name and code
/cc language listList every available language, marking the current one
/cc language set <code>Switch language and write it to config.yml
/cc language reloadRe-read the language files (use this after editing YAML)
 
/cc language set zh_cn
/cc language list
/cc language reload

/cc reload

Does four things, always in this order:

  1. re-reads config.yml;
  2. re-parses every firework style and chance;
  3. reloads the language files;
  4. unregisters and re-registers the /cc and /confetti aliases — so alias switches also apply without a restart.
!

/cc reload does not run config migration and does not re-register the root command. If you changed config-version or swapped the jar, do a full restart.

Permission nodes

NodeDefaultPurpose
creeperconfetti.commandopBase permission; without it even help is unavailable
creeperconfetti.command.effectopStyle management, including gui
creeperconfetti.command.chanceopView and change the overall chance
creeperconfetti.command.languageopSwitch and reload the language
creeperconfetti.command.reloadopReload the plugin

creeperconfetti.command lists the four sub-permissions as children, so granting the base node to an admin group is usually enough:

# LuckPerms: grant full access
/lp group admin permission set creeperconfetti.command true

To let someone edit styles but not reload the plugin, grant the child nodes explicitly:

/lp user Steve permission set creeperconfetti.command true
/lp user Steve permission set creeperconfetti.command.effect true
/lp user Steve permission set creeperconfetti.command.reload false
i

The help screen only lists entries you have permission for, so a low-privilege player sees a shorter list. That is intended.

Tab completion

Completion is permission-aware; subcommands you cannot use never appear as suggestions:

  • first level: every subcommand you have access to;
  • after /cc effect: list / add / set / remove / reset / preview / chance;
  • after /cc effect set|remove|preview|chance: existing style names, plus reset for chance;
  • after /cc language set: every language code;
  • after /cc help: subcommand names.

Style names are read from memory, so a style added a second ago is already tab-completable.

指令与权限

主指令是 /creeperconfetti，默认注册 /cc 与 /confetti 两个别名。所有功能都以子命令形式组织。

指令总览

子命令别名作用仅玩家
help [页码|命令]?、h分页帮助，可点击翻页否
effect <操作>effects、style、styles、firework管理烟花样式与样式概率部分操作
chance [百分比]probability、percent查看或设置整体触发概率否
guimenu打开图形化管理界面是
language <操作>lang查看、切换、重载语言否
reloadrl重载配置、样式、语言与别名否

不带任何参数执行 /cc 等同于 /cc help。输入了不存在的子命令时，会提示未知子命令并自动打开第一页帮助。

/cc effect

样式的增删改查都在这里。方括号表示可选参数，尖括号表示必填。

用法说明权限限制
/cc effect list列出全部样式：序号、名称、效果数量、当前概率effect—
/cc effect add [名称]把主手中的烟花保存为新样式；省略名称时自动命名为 style1、style2…effect仅玩家
/cc effect set <名称>用主手中的烟花覆盖指定样式（不存在则新建）effect仅玩家
/cc effect remove <名称>删除样式，别名 deleteeffect—
/cc effect reset恢复四个内置样式并重新平均分配概率effect—
/cc effect preview [名称]在脚下预览指定样式；省略名称则随机预览一个，别名 testeffect仅玩家
/cc effect chance查看所有样式的概率与合计effect—
/cc effect chance <名称> <百分比>把该样式固定在指定概率，其余自动补偿effect—
/cc effect chance reset所有样式概率重置为平均分配effect—

示例

# 看看现在有哪些样式
/cc effect list

# 手持一支带效果的烟花，存成名为 festival 的样式
/cc effect add festival

# 让它占一半的出现概率，其余样式按原比例分摊剩下的一半
/cc effect chance festival 50

# 单独预览一下
/cc effect preview festival

# 玩腻了删掉
/cc effect remove festival

样式名不区分大小写，Classic 与 classic 指向同一个样式；但显示与写回配置时保留最初创建时的大小写。

i

add 与 set 成功后会自动在你所在位置放一次预览烟花，省得再敲一次 preview。

/cc chance

用法说明
/cc chance显示当前整体触发概率
/cc chance <0-100>设置整体触发概率，立即写回配置
 
/cc chance 100     # 每只苦力怕都变烟花
/cc chance 5       # 百分之五
/cc chance 0       # 临时关闭（等价于不装插件）

超出 0–100 或非数字会被拒绝并提示。这个值与样式权重是两个独立维度：先判定要不要变，再抽样式。

/cc gui

打开 54 格的样式管理界面，功能与 /cc effect 等价，但全部可视化操作。使用 creeperconfetti.command.effect 权限，仅玩家可用。详见 图形界面。

/cc language

用法说明
/cc language 或 /cc language info显示当前语言的显示名与代码
/cc language list列出全部可用语言，当前项带标记
/cc language set <代码>切换语言，同时写入 config.yml
/cc language reload重新读取语言文件（改过 yml 后用这个，不必重启）
 
/cc language set zh_cn
/cc language list
/cc language reload

/cc reload

一次性完成四件事，顺序固定：

  1. 重新读取 config.yml；
  2. 重新解析全部烟花样式与概率；
  3. 重新加载语言文件；
  4. 注销并重新注册 /cc、/confetti 别名（因此改完别名开关也无需重启）。
!

/cc reload 不会执行配置版本迁移，也不会重新注册主指令。如果你修改了 config-version 或换了 jar，请完整重启服务端。

权限节点

节点默认作用
creeperconfetti.commandop基础权限，所有子命令的前置条件。没有它连 help 都用不了
creeperconfetti.command.effectop样式管理，包含 gui
creeperconfetti.command.chanceop查看与修改整体触发概率
creeperconfetti.command.languageop切换与重载语言
creeperconfetti.command.reloadop重载插件

creeperconfetti.command 通过 children 把四个子权限串在一起，因此给普通管理员授权时只需给基础权限：

# LuckPerms 示例：授予完整管理权限
/lp group admin permission set creeperconfetti.command true

只想让某个人调整样式、不允许他重载插件，就单独给子权限：

/lp user Steve permission set creeperconfetti.command true
/lp user Steve permission set creeperconfetti.command.effect true
/lp user Steve permission set creeperconfetti.command.reload false
i

帮助菜单只会显示你有权限看到的条目，所以低权限玩家打开 /cc help 时列表会短一些，这是预期行为。

Tab 补全

补全按权限过滤，没有权限的子命令不会出现在候选项里：

  • 第一层：补全所有你有权限的子命令；
  • /cc effect 之后：补全 list / add / set / remove / reset / preview / chance；
  • /cc effect set|remove|preview|chance 之后：补全现有样式名，chance 还会补一个 reset；
  • /cc language set 之后：补全全部语言代码；
  • /cc help 之后：补全子命令名。

样式名是实时从内存里取的，刚 add 完立刻按 Tab 就能补出来。
