In-game GUI

If you would rather not touch YAML, the whole style workflow is clickable: preview, adjust chances, delete, and import the firework you are holding.

Opening the GUI

/cc gui      # alias: /cc menu

Requires creeperconfetti.command.effect and a player sender. The title comes from gui.title in the language file (default "Firework styles").

A 54-slot inventory: the top 45 slots are the styles in order, the bottom row is the control bar.

If your main hand does not hold a rocket with an effect, clicking "Add" prints "Please hold a firework rocket with effects in your main hand". A newly created style appears in the list immediately with the average chance.

Style edit page

A 27-slot inventory titled with the style name, with the chance display in the middle and a ring of +/- buttons around it.

Every adjustment applies immediately: the screen refreshes, the chance is written to config.yml, and the set is rebalanced. Clicking +10% five times is exactly /cc effect chance <name> 50.

!

Delete has no confirmation step — the style is gone the moment you click. Preview it with /cc effect preview first, or back up config.yml.

Edge cases

  • More than 45 styles: paging arrows appear automatically;
  • down to a single style: it takes the full 100%;
  • deleting the last style leaves an empty list — use "Add style" to start again;
  • a chance will not go higher because the total is already 100% and the others sit at 0 — click "Even out chances" to recover.

图形界面

不想改 YAML 的话，整个样式管理都可以在箱子里点完：预览、调概率、删除、把手里这支烟花存进去。

打开界面

/cc gui      # 别名 /cc menu

需要 creeperconfetti.command.effect 权限，且只能由玩家执行。界面标题取自语言文件的 gui.title（默认「烟花样式管理」）。

点「添加烟花样式」时，如果你主手拿的不是带效果的烟花火箭，会在聊天栏提示「请在主手中拿着带有烟花效果的烟花火箭」。新建的样式会立刻出现在列表里，并自动获得平均概率。

每一次加减都是即时生效的：界面刷新、概率写回 config.yml、并再平衡一次。所以连续点 +10% 五次就等于 /cc effect chance <名称> 50。

!

删除操作没有二次确认弹窗，点下去样式就没了。删除前先 /cc effect preview 看一眼，或者提前备份 config.yml。

界面里的边界情况

  • 样式多到超过 45 个时自动分页，翻页按钮才会出现；
  • 删到只剩一个样式时，它会自动占满 100%；
  • 删除最后一个样式后界面为空，用「添加烟花样式」重新建立；
  • 概率加不上去是因为已经 100%，其它样式已被压到 0，此时可以点「平均分配」复位。
