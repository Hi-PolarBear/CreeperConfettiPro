Auto detection

With language: auto the plugin looks up the country of the server's public IP during enable, then maps it to a language.

  • Six public GeoIP endpoints are queried in parallel; the first valid answer wins, so one dead or rate-limited API cannot break detection;
  • 3 s connect and 3 s read timeouts, 6 s total, then it gives up;
  • If everything fails it falls back to en_us and logs [GeoIP] All region APIs failed;
  • After the lookup it hops back onto the main thread (the global region thread on Folia) before touching any Bukkit state.

Custom language files

Files live in plugins/CreeperConfettiPro/languages/ and are plain YAML. Edit the text and run /cc language reload.

command:
  no_permission: "&cYou do not have permission to use this command!"
  reload_success: "&aConfiguration reloaded!"
help:
  header: "&6&l=== CreeperConfettiPro help ==="
effect:
  list_header: "&6=== Firework styles (&e{0}&6) ==="
  chance_set: "&aStyle '&e{0}&a is now &f{1}%&a."
RuleDetails
Placeholders{0}, {1}… are filled by the plugin; order matters, repetition is fine
Missing keysFall back to the en_us text, so you can translate only what you care about
Overwrite policyFiles are only written when missing; your edits are never replaced
ResetDelete the file and restart to regenerate the original
Console messagesThe console.* strings are built into the jar and cannot be changed via language files

Key groups: command.* generic messages, help.* the help screen, effect.* style operations, chance.* chances, language.* language management, gui.* interface text.

v

Want a brand new language? Copy en_us.yml to xx_yy.yml and translate. Note that only the 18 built-in codes are loaded — a new code has to be added to SUPPORTED_LANGUAGES in the source.

自动检测原理

当 config.yml 中 language: auto 时，插件会在启用阶段异步查询服务器公网 IP 所在国家，再映射到对应语言。

  • 同时向 6 个公开 GeoIP 接口发起请求，谁先返回有效结果就用谁——单个接口挂掉或被限流不影响检测；
  • 单次连接与读取超时各 3 秒，整体上限 6 秒，超时后直接放弃；
  • 全部失败时回退到 en_us，并在控制台打一条 [GeoIP] All region APIs failed 警告；
  • 查询完成后回到主线程（Folia 为全局区域线程）再应用语言，避免线程安全问题。

自定义语言文件

语言文件位于 plugins/CreeperConfettiPro/languages/，是普通的 YAML。直接改文案即可，改完执行 /cc language reload 生效。

command:
  no_permission: "&c您没有权限使用此命令！"
  reload_success: "&a已重新加载配置！"
help:
  header: "&6&l=== CreeperConfettiPro 帮助 ==="
effect:
  list_header: "&6=== 烟花样式列表 (&e{0}&6) ==="
  chance_set: "&a样式 '&e{0}&a' 的概率已设为 &f{1}%&a。"
规则说明
占位符{0}、{1}… 由插件填充，顺序不能改，可以重复使用
缺失键自动回退到 en_us 的对应文案，所以可以只翻译想改的部分
文件覆盖只有文件不存在时才会写入默认内容，你的修改不会被插件覆盖
恢复原文删除该文件后重启，插件会重新生成一份
控制台消息console.* 系列文案内置于插件中，无法通过语言文件修改

常见键名分组：command.* 通用提示、help.* 帮助菜单、effect.* 样式操作、chance.* 概率、language.* 语言管理、gui.* 界面文字。

v

想做一份全新语言？复制 en_us.yml 为 xx_yy.yml 再逐条翻译即可。注意插件只识别内置的 18 个语言代码，全新代码需要在源码里加入 SUPPORTED_LANGUAGES 才会被加载。
